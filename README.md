# Mohammad Muhib Ullah — Cybersecurity Portfolio

A professional personal portfolio website showcasing expertise in red teaming, ethical hacking, penetration testing, vulnerability assessment, networking, and IT infrastructure management.

## Features

- **Responsive Design**: Fluid wide container layout optimized for all screen sizes (from 360px mobile to 1850px+ ultra-wide displays).
- **Dark Cybersecurity Theme**: Sleek terminal-inspired aesthetic with neon green (`#00E5A8`) and cyan (`#00B8FF`) accents.
- **Interactive Navigation**: Balanced 3-column header featuring logo, evenly spaced navigation links, and action buttons.
- **Professional Background**: Comprehensive detailing of experience including Junior Red Team Analyst internship, UK IT Support (4 years), and IT Officer roles.
- **Core Skills & Specializations**: Categorized expertise across Red Teaming, Vulnerability Assessment, Web Application Security, Network Security, System Administration, and Security Operations.
- **Certifications & Training**: Verified credentials including CEH training, Masterclasses, and Offensive Security Pathways.
- **Security Project Portfolio**: Filterable project showcases with interactive detail views.
- **Secure Contact & CV Download**: Fully validated contact form with success feedback and direct PDF CV download.

## Technologies Used

- **Framework**: Next.js 14 (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Animations**: Framer Motion
- **Icons**: Lucide React
- **Feedback**: Canvas Confetti

## Installation & Local Development

1. Clone the repository:
   ```bash
   git clone https://github.com/AiSecurityServices/CEO-Profile.git
   cd CEO-Profile
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run the development server:
   ```bash
   npm run dev
   ```

4. Open [http://localhost:3000](http://localhost:3000) in your browser.

---

## Production Build

To build the application for production:

```bash
npm run build
npm start
```

---

## Environment Variables

Copy `.env.example` to `.env.local` and configure required values:

```env
NEXT_PUBLIC_SITE_URL=http://localhost:3000
```
